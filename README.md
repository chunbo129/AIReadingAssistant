# 📖 KOReader AI 阅读助手 (AI Reading Assistant)

让 AI 成为你的贴身阅读伙伴！

这款插件为 KOReader 深度集成了大语言模型（LLM），通过重构与优化，它不仅能让你在阅读时随时调用 AI 深度解析，还通过精简系统冗余菜单，为你打造一个更纯净、更现代的阅读界面。

---

## ✨ 核心亮点

*   **多维划词解析** 💬：内置三个可完全自定义的快捷指令（默认：概念解析、句子翻译、语法解析）。长按选词后，一键触发深度 AI 响应。
*   **AI 智能词典** 📕：**深度集成至原生查词界面**。在查询单词时，你可以直接点击“AI 词典”，获取结合当前上下文的精准定义、例句及词源分析。
*   **智能选区扩展** 🔍：**自动识别句子边界**。开启后，即使你只划选了一个短语，插件也会自动向前后扩展至完整的句子发送给 AI，确保 AI 拥有足够的语境提供精准回答。
*   **纯净 UI 体验** 🧹：**自动精简冗余菜单**。插件会自动移除 KOReader 划词弹出框中不常用的项（如：维基百科、查看 HTML、分享、终端等），让阅读界面回归本质。
*   **交互深度优化** ⚡：**无缝返回阅读**。优化了对话框关闭后的逻辑处理，关闭 AI 窗口时会自动清理选区并精准返回阅读位置，不会产生界面卡顿或选区残留。
*   **连续对话能力** ✍️：支持在 AI 窗口中直接输入追问，像使用 ChatGPT 一样与书籍内容进行深度、连贯的交流。
*   **笔记一键保存** 📝：AI 产出的精彩内容可直接保存为 KOReader 高亮笔记，方便日后回顾复习。
*   **极致兼容性** 🔧：完美支持 OpenAI (ChatGPT)、Claude、Gemini、DeepSeek、火山引擎 (豆包)、通义千问等所有兼容 OpenAI 接口的服务。

## 🚀 快速上手

### 第一步：下载插件

1.  点击本页面右上角的 **Code** 按钮，选择 **Download ZIP**。
2.  解压下载的文件，得到 `aireadingassistant.koplugin` 文件夹。

### 第二步：配置 AI 密钥

1.  进入 `aireadingassistant.koplugin` 文件夹。
2.  找到 `configuration.lua.sample` 文件并**重命名为 `configuration.lua`**。
3.  使用文本编辑器打开，填入您的配置：
    *   `api_key`: 您的 AI 服务密钥（**必填**）。
    *   `model`: 想要使用的模型名称（如 `gpt-4o`, `deepseek-chat`, `doubao-pro-4k` 等）。
    *   `api_endpoint`: API 接入点地址。

### 第三步：安装与重启

1.  将配置好的 `aireadingassistant.koplugin` 文件夹复制到设备的 `koreader/plugins/` 目录下。
2.  **重启 KOReader**。
3.  **使用方式 A (划词)**：长按选中文字，在菜单中点击“概念解析”等。
4.  **使用方式 B (查词)**：点击单词弹出原生词典后，点击左下角的“AI 词典”。

## 🔧 进阶自定义

您可以在 `configuration.lua` 中自由调整以下内容：

*   **自定义指令**：修改 `prompt1-3` 和对应的 `menu_text1-3`，定制专属的阅读工作流。
*   **智能选区开关**：设置 `auto_expand_to_sentence = true`，让 AI 总是能看到完整的句子。
*   **响应限制**：调整 `max_ai_response_lines` 以控制窗口中显示的回答长度。

## ❓ 常见问题

*   **问：菜单清理功能太激进了，我想找回原来的菜单怎么办？**
    *   答：你可以编辑 `menu_cleaner.lua` 文件，注释掉不需要删除的项，或者直接在 `main.lua` 中取消对 `menu_cleaner` 的引用。
*   **问：支持哪些模型？**
    *   答：只要支持标准 OpenAI 接口的模型（包括绝大部分国产大模型）都能完美运行。
*   **问：界面显示异常？**
    *   答：建议在 Prompt 中要求 AI “返回纯文本，不要包含 Markdown 符号”，以获得最佳显示效果。
